\# Olivia-bot



A free, self-hosted n8n workflow that sends a daily philosophical dilemma to Telegram and answers on demand when you message it "state your wisdom".



Each dilemma is generated by Gemini from a random thinker (Nietzsche, Camus, Socrates...) and a random theme. It's written to challenge a comfortable belief, with no easy answer.



\## How it works

\- \*\*daily-dilemma workflow:\*\* Schedule Trigger -> Gemini -> Telegram

\- \*\*wisdom listener workflow:\*\* polls Telegram every minute -> keyword check -> Gemini -> Telegram reply (a hint is sent if the keyword is missing)

\- If Gemini errors (for example the free quota runs out), a fallback message is sent instead.



\## Stack

n8n (self-hosted in Docker), Telegram Bot API, Google Gemini free tier.



\## Setup

1\. Create a bot with @BotFather and copy the token.

2\. Import both JSON files from `workflows/` into n8n.

3\. Create Telegram and Google Gemini credentials in n8n.

4\. In the listener's HTTP Request nodes, replace `YOUR\_BOT\_TOKEN`. Replace `YOUR\_CHAT\_ID` wherever it appears.

5\. Set your timezone in workflow settings, then publish both workflows.



\## Notes

\- Runs only while your machine and Docker are on.

\- Never commit your real bot token.
